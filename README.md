## Abstract

The **Online Auction & Bidding System** is a simple Java-based program that allows a user to participate in an auction by entering an item name, its starting price, and a bid amount. The program accepts user input using the `Scanner` class and stores the item name as a `String` and the prices as `int` values. It then compares the user’s bid with the starting price using a conditional `if-else` statement. If the bid is higher than the starting price, the program accepts the bid and displays the item name and winning bid. If the bid is equal to or lower than the starting price, the program rejects the bid. The project demonstrates basic Java concepts including input handling, variables, data types, operators, conditional statements, classes, methods, and output.

## How It Works

1. The user enters the item name.
2. The user enters the starting price.
3. The user enters their bid amount.
4. The program compares the bid with the starting price.
5. If the bid is higher, the bid is accepted.
6. If the bid is equal to or lower than the starting price, the bid is rejected.
7. The program displays the final result.
